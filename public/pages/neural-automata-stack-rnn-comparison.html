Grefenstette Stack-RNN (2015)

Neural Stacks · Unbounded · Strength-based

Overview

Grefenstette Stack-RNN 2015

Core idea. The stack is an unbounded list of (value, strength) pairs. Strength is a continuous scalar in [0, 1] representing how "alive" an element is — it is not binary.

Actions. Two independent Sigmoid outputs: a push strength and a pop strength. They do not sum to one — both can be high simultaneously, which is legal. There is no noop; near-zero values on both approximate it.

Reading. The controller reads a weighted sum over the entire stack, top-to-bottom, drawing up to 1.0 total weight. Elements near the top consume most of the budget; once exhausted, deeper elements contribute nothing.

Update. Pop erodes strength from the top down, consuming a "pop budget." Each element's strength is reduced by however much budget remains when the pop reaches it. A new element is always appended with push_strength, regardless of pop.

Stack grows? Yes — unbounded. One element is appended every timestep. Old zeroed-out elements linger but contribute nothing to the reading.

Joulin Stack-RNN (2015)

Superposition Stack · Bounded 3D Tensor · 3-way Softmax

Overview

Joulin Stack-RNN 2015

Core idea. The stack is a dense 3D tensor rather than a list. Every timestep all three possible operations — push, pop, and noop — are computed simultaneously and blended by their probabilities. The result is a "superposition" stack that has partially done all three.

Actions. A single Softmax over three options: push, pop, noop. They sum to 1. Including noop is important — it lets the model leave the stack unchanged without paying into a push or pop. Multiple independent stacks can each have their own distribution.

Reading. Simply returns the top element (index 0 along the depth axis). No weighted sum. If the stack is empty, returns zeros.

Update. Each depth position of the new stack is a probability-weighted blend of what push, pop, and noop would each place there. A "jagged sum" handles the fact that each outcome has a different number of elements. The stack grows by 1 each step but is capped at min(t, T−t, max_depth).

Stack grows? Yes, but bounded — the height cap automatically shrinks back toward sequence end, since there can't be more net pushes than remaining steps.

Suzgun Stack-RNN (2019)

Fixed-size Stack · 2-way Softmax · W_sh injection

Overview

Suzgun Stack-RNN 2019

Core idea. A pre-allocated, fixed-size 2D tensor acts as the stack. It never changes shape — push shifts elements down and drops the bottom row; pop shifts elements up and pads with zeros at the bottom.

Actions. Two mutually exclusive actions — push and pop — from a Softmax, so they always sum to 1. There is no noop, which means the stack is always forced to move. Variants differ in how the Softmax is computed: standard, temperature-scaled, or Gumbel.

Reading. The top element (index 0) is read and projected into hidden space via a learned matrix W_sh. This projection is then added to the previous hidden state before the RNN step — not concatenated to the input. This is the most distinctive difference from Grefenstette Stack-RNN and Joulin Stack-RNN.

Update. The new stack is a 2-way blend of the push-shifted and pop-shifted versions of the current stack. Because the stack is fixed-size, pushing always silently truncates the bottom row — information at the bottom is permanently lost.

Stack grows? No — fixed at memory_size × memory_dim forever.

Suzgun Baby-NTM (2019)

Fixed N-slot Buffer · 5 Rotation/Shift Ops · Read & Write at M(0) · Monoid Actions

Overview

Suzgun 2019

Core idea. Replace the unbounded stack of the Stack-RNN with a fixed-size circular buffer of N scalar slots. The model chooses a soft blend of five memory operations at each step via a 5-way softmax. Access is always through M(0) — the front slot.

Actions. Five operations, each an N×N matrix applied to the buffer: ROTATE-RIGHT — bring last to front [e,a,b,c,d]; ROTATE-LEFT — move first to back [b,c,d,e,a]; NO-OP — unchanged; POP-LEFT — shift left, zero at back [b,c,d,e,0]; POP-RIGHT — shift right, zero at front [0,a,b,c,d]. These form a monoid under matrix multiplication.

Reading. Always M(0). Injected additively into the hidden state before the RNN step: h̃t-1 = ht-1 + Wm·M(0)t-1. This matches the Suzgun Stack-RNN injection style — additive, not concatenation.

Writing. Two-stage: (1) the buffer is updated as M_t = Σ ai·OPi·Mt-1 (soft superposition of all 5 ops); (2) a new scalar nt = σ(Wn·ht) is added to M(0)t. Rotation navigates; injection inserts.

vs. Suzgun Stack-RNN. The Suzgun Stack-RNN in the same paper uses a fixed-size 2D tensor with push+pop; Baby-NTM replaces that with a 1D rotating buffer and 5 ops. Both share additive injection and fixed memory size.

DuSell & Chiang (2022) — NS-RNN / RNS-RNN

Nondeterministic Stack · WFA · 3 typed ops · Quadratic memory

Overview

DuSell & Chiang 2022

Core idea. Instead of one concrete stack, the model maintains α[j] — a distribution over all (state, stack-top) configurations (q, x) ∈ Q×S. This is the marginal of a full WFA (Weighted Finite Automaton) over stack runs. The underlying DP table γ[i→j] stores the probability of every edit path from timestep i to j.

Operations. Three typed transitions per source pair (q, x): push(q,x→r,y) transitions to state r and pushes y; repl(q,x→r,y) replaces x with y; pop(q,x→r) removes x and goes to r. A single log_softmax over all Q·S + Q·S + Q columns (per source row) gives a joint probability.

Reading. The reading is softmax(flatten(α[j])) — a Q·S-dimensional probability vector representing the marginal distribution over (state, top-symbol) configurations. This is qualitatively different from the deterministic stacks: there is no single "top element," only a distribution.

Update. At each step j the model fills in a new column of γ using three einsum recurrences: push from the previous α row, repl by "following" the last column of γ with the repl weights, and pop by composing two sub-columns of γ via an intermediate γ′. Then α[j] is recomputed from α[:j] and γ[:,j].

Memory. O(n² · Q²S²) — the full γ tensor is n×n. Sequence length must be fixed at construction time. Quadratic cost is the main practical limitation.

What "branches run in parallel via DP" means. A nondeterministic PDA can take multiple valid transitions at any step — conceptually forking into parallel branches. After n steps there could be exponentially many branches. Rather than tracking each branch explicitly, the DP keeps compact summaries: α[j][q,x] = total weight of all runs up to step j that end in state q with symbol x on top, and γ[i→j][...] = total weight of all stack edits from step i to j. Advancing to step j+1 extends these tables by one column using the new transition weights — you never enumerate individual branches. The model implicitly considers every possible parse in parallel, and the reading is a weighted average over all of them.

DuSell & Chiang (2022) — VRNS-RNN

Vector Nondeterministic Stack · WFA + embeddings · reading ∈ ℝ^{Q·S·m}

Overview

DuSell & Chiang 2022

Core idea. Extends NS-RNN by giving each WFA path an m-dimensional embedding vector. A second DP table ζ[i→j][q,x→r,y,k] runs in parallel with γ, carrying the vector content accumulated along each path. The scalar weight γ and vector weight ζ are updated together each step.

Additional output. At every push the controller predicts a pushed_vector ∈ ℝᵐ (via a Linear + LogSigmoid layer). This vector is embedded into the ζ table at the push entry, then propagated forward by repl and pop recurrences.

Reading. η[j][r,y,:] is the α-weighted average of ζ vectors — the expected embedding for each (state, symbol) slot. The reading is η/Σα, shaped Q×S×m and flattened to Q·S·m dimensions. This gives the controller much richer stack information than the scalar α alone.

Bottom symbol. ζ[−1→0] is initialised to a learnable (or fixed) bottom_vector ∈ ℝᵐ, so the stack always starts with a concrete embedding, not just a scalar weight.

Memory. O(n² · Q²S² · m) — same quadratic growth as NS-RNN but scaled by the embedding dimension.

Deletang Tape-RNN (2023)

Unbounded Tape · Head Pointer · 5 Write/Jump Ops · Context-Sensitive

Overview

Deletang Tape-RNN 2023

Core idea. An RNN with a differentiable 1D tape and an explicit movable read/write head (pointer). Unlike stack models where memory is always accessed at the "top", the Tape-RNN head can be positioned anywhere on the tape. This gives it the expressive power of a linear bounded automaton — placing it at the Context-Sensitive level of the Chomsky hierarchy.

Actions. Five differentiable operations, softmax-weighted: WRITE-RIGHT — write v_t at ptr, ptr += 1; WRITE-LEFT — write v_t at ptr, ptr −= 1; WRITE-STAY — write v_t at ptr, ptr unchanged; JUMP-RIGHT — ptr += ℓ (no write); JUMP-LEFT — ptr −= ℓ (no write). JUMP ops use the input length ℓ as stride for fast long-distance traversal.

Reading. tape[ptr] — a d-dim real vector at the current head position — is concatenated with input x_t and fed to the RNN controller. Unlike Baby-NTM which always reads M(0), the Tape-RNN reads wherever the head is.

Writing. Soft write: tape[ptr] ← w_write·v_t + (1−w_write)·tape[ptr], where w_write = a_WR + a_WL + a_WS (total write weight). JUMP ops contribute zero to the write. The head's expected displacement is Σ a_i·δ_i over all five ops.

Inspired by Baby-NTM. The paper credits Baby-NTM (Suzgun 2019) as inspiration but makes two key changes: (1) tape is unbounded; (2) head moves by explicit position shifts rather than rotating the whole buffer, giving true random access anywhere on the tape.

Chomsky level. Empirically reaches Context-Sensitive tasks (duplicate string, bucket sort) where all stack models fail. Tape size is bounded in practice by sequence length (linear bounded automaton), not infinite.
