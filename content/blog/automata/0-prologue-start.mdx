Computers are fascinating things. [It is said](https://web.mit.edu/6.001/6.037/sicp.pdf), we conjure the *spirit of computers* with our spells!

How do these spirits think? Is it like a human brain?

One of my first working software was a neural network, $3$ days to write on paper and code in `numpy`. It was trained on the Titanic dataset. Going from regression (n$00$b) to NN gave $~30\%$ improvement and when I added some eval data, it became even better (n$00$b). But it was very cool! A `.npz` file with numbers that could do a better “if-else” than I could code and I could put it in a pendrive and carry it around. I thought these weights would be like gold and NN would take over the world (not n$00$b).

$10$ years later that prediction was true. LLMs are a type of NN and they are already insanely good. [AGI is finally here](https://openclaw.ai/) (sarcasm) and it has [changed culture forever](https://lucumr.pocoo.org/2026/1/18/agent-psychosis/). But they haven’t replaced the if-else code we write, rather NN provides a very rich perception and augmentation to that decision making.

I recently wanted to do research in AI.

Just like everyone-fucking-else.

But I knew it was not LLMs, Agentic, AGI but teaching NNs to behave like computers.

All are independent essays can be read in any order.

I have also created a lot of supplementary material to understand existing work done in this direction.

- [#$1$ - Task Visualizer](/pages/neural-automata-task-visualizer.html): There are about 33 algorithms that if a model generalises to, we can claim to have built a general purpose neural computer i.e. a neural automata. These include simple things like Dyck-n languages, binary arithmetic to complex tasks like Travelling Salesman Problem.  
- [#$2$ - Stack Memory Models](/pages/neural-automata-stack-memory-models.html): There are some RNN based models that connect to an external stack memory. These are useful to solve many tasks and can be programmed to be simple computers.  
- [#$3$ - Matrix (Random Access) Memory Models](/pages/neural-automata-matrix-memory.html): Moving a step ahead from Stack, we get to models that can access any part of the memory thus being able to solve complex graph problems.  
- [#$4$ - Implicit Memory Models](/pages/neural-automata-implicit-transformers.html): These models do not have a dedicated memory like LSTMs or **Transformers**. These are generally not very powerful but there are some up-coming ideas to look out for.
